## Audit findings — verdicts

1. "BudgetGuard not used by production inference" — CORRECT in v1.1.0; FIXED (matrix row 1; the caller is `MeteredBrain.complete`, the single provider door).
2. "Small-model module disconnected" — CORRECT; FIXED (registry construction wraps local providers).
3. "Handoffs only in the harness" — CORRECT; FIXED (orchestrator call sites + source-anchored guards).
4. "Registry not connected to routing" — CORRECT for routing (test/probe were); FIXED (select → provider config → resolver).
5. "Memory retrieval unverified" — PARTIALLY INCORRECT: retrieval was ALWAYS wired (`_build_system_prompt` layers 3+4); what was missing was VERIFICATION — now provided (row 5).
6. "Upstream credential namespace shared" — CORRECT (deliberate v1.0.0 continuity); REVERSED per this audit (row 7).
7. "Frontend lacks verified integration" — CORRECT; the Road Dog panel now vitest-tests against the real API contract (row-level evidence in the test report).
8. "Frontend bundle missing" — CORRECT; low-memory strategy implemented, transform still OOM-killed under the 4 GiB cgroup; script + evidence shipped, distribution labelled.
9. "Docs inconsistent about the compiled frontend" — CORRECT; v1.2.0 docs state the source-only distribution and the build requirement.
10. "Regression suite unfinished" — CORRECT; batched sweep executed with persisted logs (test report).
